# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com),
and this project adheres to [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-03-25

### Added

- Animated splash screen with scrambling/revealing ASCII art title in rainbow colors
- Live git integration with real commits, branches, refs, and file changes
- ASCII commit graph with lane-based rendering and merge connectors
- Working directory changes visualization (staged, unstaged, untracked files)
- Branch info bar showing current branch, tracking status, and ahead/behind counts
- Commit explorer with fuzzy search across messages, hashes, authors, refs, files, and dates
- Unified diff viewer with color-coded additions/deletions
- Clipboard support to copy commit SHA
- Performance optimizations with commit list caching
- Keyboard-driven navigation with vim-style and arrow key support
- Comprehensive test suite with 100+ passing tests
- GitHub Actions CI/CD pipeline with type checking, linting, and building

### Fixed

- Initial release

### Changed

- Project structure and configuration
